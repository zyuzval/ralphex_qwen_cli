# ralphex_qwen_cli

## Эксперимент завершён

Весной 2026 года этот форк создавался как попытка использовать бесплатные лимиты Qwen для автономной работы с кодом, с учётом возможностей AI-агентов на тот момент.

За прошедшее время возможности агентов выросли, и эксперимент потерял для автора практический смысл. Разработка остановлена; репозиторий сохранён как история эксперимента, а не как поддерживаемый продукт.

Исходная документация Ralphex удалена из этого README, чтобы не создавать впечатление, что она описывает состояние и возможности данного форка.

Форк основан на проекте `umputun/ralphex`. Код, история изменений и исходные лицензии сохранены.
