# Agentic RAG + MCP

## Обзор архитектуры

Данная диаграмма иллюстрирует интеллектуальную систему поиска и генерации ответов, объединяющую **Agentic RAG** (Retrieval-Augmented Generation с агентным поведением) и **MCP** (Model Context Protocol).

---

## Компоненты системы

### 1. Chat Interface
- Поле ввода вопроса
- Кнопка Submit
- Отображение пользовательского аватара

### 2. Поток обработки запроса

#### Шаг 1: Анализ запроса (Analyse the Query)
**Компонент:** LLM с возможностью перезаписи запроса

**Решение:** *"Do I need additional data for the answer?"*
- **Yes** → Переход к LLM Agent
- **No** → Прямой переход к генерации ответа

#### Шаг 2: LLM Agent + MCP Servers
При необходимости дополнительных данных:

**LLM Agent** взаимодействует с несколькими **MCP Servers**:
- MCP Server 1 (иконки: 🔧 🧠 📄)
- MCP Server 2 (иконки: 🔧 🧠 📄)
- MCP Server 3 (иконки: 🔧 🧠 📄)

*MCP (Model Context Protocol) обеспечивает стандартизированный интерфейс для подключения внешних инструментов и источников данных.*

#### Шаг 3: Rerank Search Results
- Переранжирование результатов поиска
- Улучшение релевантности retrieved контекста

#### Шаг 4: Generate Answer
**Компонент:** LLM
- Генерация финального ответа на основе контекста

#### Шаг 5: Анализ ответа (Analyse the Answer)
**Решение:** *"Is the answer correct/relevant to the Query?"*

**Цикл обратной связи:**
- **Yes** → Ответ возвращается пользователю
- **No** → Перезапись запроса (Rewrite the Query) и повторный цикл

---

## Циклы системы

### Основной цикл (RAG)
```
User Query → Analyse → [Retrieve via MCP] → Rerank → Generate → Answer
```

### Цикл самокоррекции
```
Analyse Answer → No → Rewrite Query → Analyse Query → ...
```

---

## Ключевые особенности

| Особенность | Описание |
|-------------|----------|
| **Агентность** | LLM принимает решения о необходимости поиска данных |
| **MCP интеграция** | Модульное подключение множества источников данных |
| **Self-correction** | Проверка качества ответа с возможностью перезапроса |
| **Query Rewriting** | Оптимизация запросов для улучшения результатов |
