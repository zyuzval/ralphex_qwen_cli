# Plan: Code Review qwenex проекта

## Описание
Провести полную проверку кода проекта qwenex на качество, безопасность и соответствие best practices.

## Задачи

### 1. Статический анализ
1. Запустить mypy для проверки типов
2. Запустить ruff/flake8 для проверки стиля
3. Запустить bandit для проверки безопасности
4. Запустить pylint для общей оценки качества

### 2. Проверка тестов
1. Запустить все тесты (pytest)
2. Проверить coverage (цель: 80%+)
3. Найти тесты без assert
4. Найти моки без проверки вызовов

### 3. Проверка документации
1. Проверить наличие docstrings (Google style)
2. Проверить актуальность README.md
3. Проверить ссылки в документации
4. Найти undocumented public API

### 4. Проверка импортов
1. Найти циклические импорты
2. Найти неиспользуемые импорты
3. Проверить порядок импортов (stdlib, third-party, local)

### 5. Проверка обработки ошибок
1. Найти bare except
2. Найти игнорирование исключений (pass после except)
3. Проверить логирование ошибок
4. Найти потенциальные утечки ресурсов

### 6. Проверка async кода
1. Найти не-awaited корутины
2. Проверить обработку asyncio.CancelledError
3. Найти потенциальные deadlock
4. Проверить таймауты

### 7. Проверка конфигурации
1. Найти хардкод значений
2. Проверить обработку secrets (API keys)
3. Найти чувствительные данные в коде
4. Проверить валидацию конфига

### 8. Отчёт
1. Собрать все находки
2. Приоритизировать (critical, major, minor)
3. Предложить фиксы
4. Создать issues в GitHub

## Validation
- `mypy src/qwenex --ignore-missing-imports`
- `ruff check src/qwenex`
- `pytest src/tests/ -v`
- `bandit -r src/qwenex`

## Ожидаемый результат
- Отчёт с найденными проблемами
- Список файлов для исправления
- Приоритизированный план исправлений
