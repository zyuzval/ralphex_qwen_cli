## 🧠 Архитектурные решения (ADR)

*Записывай причины, не факты. «Почему» важнее «что».*

- **[2026-02-26] Выбрали Python** вместо Go — причина: MCP SDK нативный, AI-экосистема богаче, быстрее прототипирование. Спека: BOOT.md
- **[2026-02-26] Один процесс (MCP внутри)** вместо sidecar — причина: проще деплой, отладка, нет IPC overhead. Спека: BOOT.md
- **[2026-02-26] Гибридные субагенты** (2 параллельно + 3 последовательно) — причина: баланс скорости и ресурсов. Спека: docs/DECISIONS.md
- **[2026-02-26] Qwen Cloud API (MVP)** с заделом на Ollama/OpenAI — причина: фокус на MVP, интерфейс LLMProvider для расширения. Спека: BOOT.md
- **[2026-02-26] BOOT/WAL/FEAT/PROP глубокая интеграция** — причина: уникальное отличие от ralphex, структурированный контекст для AI. Спека: BOOT.md
- **[2026-02-26] Git через subprocess** вместо dulwich — причина: git CLI надёжнее, проще отладка, меньше зависимостей. Спека: BOOT.md
- **[2026-02-26] MVP без dmux/cmux** — причина: быстрее прототип, полный контроль, понимание проблем. Интеграции в v0.2. Спека: docs/DECISIONS.md
- **[2026-02-26] Лицензия MIT** — причина: совместимость с ralphex/dmux, широкое принятие. Спека: docs/DECISIONS.md
